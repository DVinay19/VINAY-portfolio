# Vinay Kumar — Portfolio

A responsive portfolio website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page content
- `style.css` — responsive design and animations
- `script.js` — mobile menu, scroll reveal, active navigation, and footer year

## Before publishing
1. In `index.html`, replace every `YOUR_EMAIL@example.com` with your real email address.
2. Replace the generic `https://github.com/` links with your GitHub profile or the correct project repositories.
3. Replace the generic `https://www.linkedin.com/` link with your LinkedIn profile.
4. Check every project description and keep only details that accurately describe your work.
5. Open `index.html` in a browser and test the navigation and contact links.

## Publish with GitHub Pages
1. Put `index.html`, `style.css`, `script.js`, and `README.md` in the root of your GitHub repository.
2. Commit and push the files.
3. On GitHub, open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for the Pages deployment to finish and open the published URL shown in Settings → Pages.

The site uses Google Fonts when online and falls back to system fonts if they cannot load. It does not require a build step.
